# Protocol research acknowledgement

The Sound BlasterX G6 USB HID protocol used by this project was independently
implemented from publicly documented reverse-engineering work:

- RizeCrime/linuxblaster_control — `UsbProtocol.md` (MIT)
- nils-skowasch/soundblaster-x-g6-cli (GPL-2.0)

This project contains a new minimal Rust implementation and does not copy source
code from those applications.
